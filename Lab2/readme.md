# FS (File System) Node JS's Module

## Major task of FS Module

- lstat()
- fstat()

- Watching for Changes
  - watch()
  - watchFile()
  - unwatchFile()

- Streaming Large File
  - createReadStream()
  - createWriteStream()

- File Operations
  - rename()
  - truncate()
  - unlink()
  - link()
  - syslink()
